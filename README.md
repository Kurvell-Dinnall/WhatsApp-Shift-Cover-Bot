# WhatsApp-Shift-Cover-Bot

## Description
This project aims to develop a mobile application that automatically monitors a user's work group chat for available shifts. The application will allow users to provide their availability and identify shift-cover messages that match their schedule.

When a suitable shift is identified, the application will automatically respond on the user's behalf, with the goal of responding quickly enough to improve the user's chances of securing the shift.

The project will also investigate the technical and regulatory challenges involved in integrating with WhatsApp, with a focus on building the application in a reliable and compliant manner.


## Features

- Automaticaly respondse to shift cover request without you needing to use your phone
- Able to add availability to only respond to shift you can cover
- Tracks shifts you are already covering
- Webhook-based integration with WhatsApp Business API for real-time message handling
- PostgreSQL database for persistent shift and availability tracking
- Rule-based matching engine to filter shift requests against user availability
